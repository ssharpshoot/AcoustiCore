# Changelog

## 3.1.0 - 2026-08-19

- Added four evidence grades and four assessment states.
- Added CTA-2010-C schema support and six-band low-frequency display.
- Blocked all 93 multi-record subwoofer models from automatic customer primary selection.
- Isolated the legacy size/power estimate as `legacy-size-power-v1`, permanently provisional.
- Separated low-frequency output capacity from multi-seat consistency guidance.
- Added axial room-mode indicators without fixed room-gain assumptions.
- Added local speaker/amplifier library, CSV/JSON import, and CSV/XLSX templates.
- Added ProjectFileV2 import/export, report traceability, version metadata, and contact QR.
- Added keyboard-complete subwoofer search and active workflow navigation.
- Added GitHub Pages verification/deployment workflow and third-party data notice.
